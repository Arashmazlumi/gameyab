# 🎮 GameYab

**GameYab** یک وب‌اپلیکیشن برای کشف و پیدا کردن بازی‌های ویدیویی است که به کاربران کمک می‌کند بازی‌های مناسب خود را راحت‌تر پیدا کنند.

## ✨ ویژگی‌ها
- 🎯 پیشنهاد بازی و کشف عناوین جدید
- 🕹️ رابط کاربری ساده و جذاب
- ⚛️ توسعه‌یافته با React

## 🚀 اجرا در سیستم شخصی

```bash
git clone https://github.com/Arashmazlumi/gameyab.git
cd gameyab
npm install
npm start
```

سپس برنامه در مرورگر اجرا می‌شود.
